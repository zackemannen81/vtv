# File Structure

- `AGENTS.md` — entry point and authoritative reading order
- `docs/` — docs-first control plane
- `docs/CURRENT_TASK.md` — sole active task charter and checklist
- `docs/PROJECT_BRIEF.md` — product intent, requirements, and open questions
- `docs/CURRENT_STATUS.md` — observed repository/project state
- `docs/SYSTEMDOC.md` — verified durable system behavior
- `docs/TASK_WORKFLOW.md` / `docs/TASK_IDS.md` — lifecycle and identity register
- `docs/adr/` — indexed consequential decisions
- `docs/backlog/`, `docs/paused/`, `docs/finished/` — inactive, blocked, and archived work
- `docs/concepts_sandbox/` — non-authoritative ideas
- `docs/JOURNAL.md` — append-only work history
